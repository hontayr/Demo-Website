# CyberStart

A friendly front door for people new to cybersecurity: free resources, a hands-on
"first hack" in your browser, and a Discord community of people who remember being
beginners too.

Live site: https://hontayr.github.io/Demo-Website/

## Preview locally

No build step. Open `index.html` in Chrome or Edge, or run a tiny local server from
this folder:

```
python -m http.server 8000
```

then visit http://localhost:8000.

## Ethics

Only hack what you own or have permission to test. The only challenge target on this
site is the site itself.
